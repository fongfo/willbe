Prototype structure

This version is designed for richer evaluation. It gives users enough detail to react to real setup behavior: choosing multiple contacts, entering assets, defining maintenance habits, and reacting to a generated readiness view.

Family users
Tests whether households want role-based setup from the start.
Trusted contacts
Tests comfort with primary and backup emergency relationships.
Asset forms
Tests whether simple reference capture is enough without secure vault behavior.
Check-ins + integrations
Tests whether ongoing maintenance and familiar cloud tools increase trust.
Readiness gaps
Tests whether automated guidance feels useful and credible.
