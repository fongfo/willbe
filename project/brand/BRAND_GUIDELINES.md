# WB-8：品牌与视觉设计方向

> 对应 Jira [WB-8](https://growth-more.atlassian.net/browse/WB-8)，所属 Epic [WB-1](https://growth-more.atlassian.net/browse/WB-1)。
> 基于 `project/Prototype Family Contingency Platform.html` 现有视觉系统提炼整理，作为 App/官网视觉规范的起点，非最终定稿（仍需设计师精修 Logo/插画）。

## 1. 品牌调性

Willbe 处理的是"万一发生意外"的敏感话题（家庭传承、紧急联系、资产交接），视觉与语调必须传达：

- **可信赖**：克制的配色、清晰的层级，避免金融App常见的浮夸渐变和加密货币行业的"赛博炫技"风格。
- **温度**：这不是冷冰冰的法律工具，而是"为家人多想一步"的关怀工具，文案与插画需要有人情味。
- **专业但不说教**：涉及保险/法律/区块链概念时，用平实语言降低门槛，不堆砌术语。

## 2. 色彩系统（沿用原型，固化为设计 Token）

| Token | 色值 | 用途 |
|---|---|---|
| `--teal`（主色） | `#0f766e` | 主按钮、强调、Logo 主色 |
| `--teal-soft` | `#dbf4ef` | 主色浅底（标签、卡片高亮背景） |
| `--gold`（强调色） | `#bf8714` | 重要提示、就绪度评分高亮、勋章类UI |
| `--gold-soft` | `#fff2d7` | 强调色浅底 |
| `--orange` | `#f97316` | 待办/提醒类状态 |
| `--orange-soft` | `#fff0e6` | 提醒浅底 |
| `--danger` | `#b54708` | 紧急情况视图、严重 Gap 警示（注意：非鲜红色，避免过度恐慌感） |
| `--danger-soft` | `#fff1eb` | 警示浅底 |
| `--navy` | `#102a43` | 深色文本/页脚背景 |
| `--text` | `#163247` | 正文 |
| `--muted` | `#647789` | 次要文本 |
| `--bg` | `#f4f8fa` | 页面背景 |
| `--surface` | `#ffffff` | 卡片/容器背景 |
| `--line` | `#d4e2e8` | 分割线/边框 |

**设计原则**：teal 为主、gold 为点缀强调（不超过 10% 视觉占比）、danger 色仅用于真正紧急/严重场景，避免滥用导致用户焦虑钝化。

## 3. 字体系统

- **正文/UI**：Inter（系统回退：Segoe UI, Arial, sans-serif）— 现代、易读、多语言（含中文需配套思源黑体/PingFang 等回退栈）。
- **标题/强调场景**：Georgia（回退：Cambria, "Times New Roman", serif）— 用于强调"正式感"的场景，如紧急移交文档标题、就绪度评分大字展示，传达"这是一份正式的家庭文件"而非普通App界面。
- **中文字体回退建议**（原型未覆盖，App/官网落地时需补充）：苹方/思源黑体（正文）+ 宋体类衬线（强调场景，对应 Georgia 的角色）。

## 4. 圆角与阴影

- 统一圆角 `18px`（`--radius`），传达柔和、非强硬金融机构感。
- 卡片阴影：`0 18px 42px rgba(16, 42, 67, 0.1)` — 轻柔漂浮感，不用强对比阴影。

## 5. 多语言与多市场适配（东南亚优先）

- 首发语言：简体中文 + 英文（马来西亚华人家庭场景）；规划新增马来语、繁体中文（新加坡/其他华人市场）。
- 视觉系统需预留中文长文本的排版空间（如紧急联系人卡片、Gap 列表项，中文字数密度高于英文，避免英文原型的留白在中文下显得拥挤）。
- 示例数据本地化：原型采用 Maybank/AIA/吉隆坡等马来西亚本地机构，App/官网素材需保持这一本地化基调，而非泛用"Bank/Insurance"占位符。

## 6. Logo 方向建议（待设计师执行）

- 概念方向：以"家"或"伞/盾"的抽象几何形态结合 teal 主色，避免使用常见的区块链行业视觉符号（链条、立方体、加密货币图标）——产品定位是家庭关怀工具，刻意与"Web3 炫技"调性区隔。
- 避免：抽象科技感渐变、赛博朋克色调、过度锐利的几何切割（这类风格与"信任/温度"的品牌调性冲突）。
